Find out when an API you depend on changes, before your users do.

Third-party APIs change without notice: a field goes missing, an ID turns from a number into a string, a value that was never null suddenly is. Drift Monitors call your endpoints on a schedule, learn their response schema and alert you as soon as it changes.

  • Learns the schema, not the valuesPrices and timestamps change on every call. Monitors only alert when the shape changes.
  • Low-noise alertsOptional fields and empty lists do not raise false alarms. A field has to be gone for three checks in a row before it counts as removed.
  • Email, Slack or webhookEach alert lists the exact paths, such as $.data[].amount, and what changed.
